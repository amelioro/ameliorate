# Frequently Asked Questions

## Is this project intended to have longevity?

This is a long-term project that is intended to last for as long as it's useful/has potential. It's currently being worked on part-time by its maintainer.

## How is this project being funded?

Ameliorate is currently being funded by its maintainer.

## Are there plans to look for funding for the project?

Ideally there would be enough funding to help hire for the [Roles to Fill](/roles-to-fill), but minimally funding would enable at least the core maintainer to work full-time on the project. Funding will not go any routes that impede accessibility or UX. Maybe offering private hosting, consulting, or workshops. Grants? Philanthropy?
